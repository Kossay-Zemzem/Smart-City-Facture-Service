# Billing Service (Service Facture)

> [!NOTE]
> This service is part of a microservice orcherstration project. For full details, please visit the **[Smart City Microservices Project](https://github.com/Kossay-Zemzem/Smart-City-Microservices)** main repository.

## Service description

The Billing Service is a core component of the Smart City platform that centralizes billing across the city’s services. It manages customer records and retrieves invoices by type (electricity, water, parking), and it receives the invoices generated by other services, such as parking reservations.

## Tech Stack

* **Framework:** Spring Boot
* **Communication Protocol:** SOAP
* **Database:** H2
